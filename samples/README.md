# 🧪 Sample Projects

These folders contain public sample outputs generated by sql2solution so developers can inspect the kind of .NET solution structure, API projects, client projects, tests, and supporting files the generator can create.

## AdventureWorksLT2017Api

[Open the sample project](AdventureWorksLT2017Api)

Generated from the AdventureWorksLT-style SQL Server schema as an ASP.NET Core API solution with application, domain, infrastructure, Razor Pages client, Blazor client, and test projects.

This sample excludes local build/editor artifacts such as `bin`, `obj`, and `.vs`.
